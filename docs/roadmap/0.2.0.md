# v0.2.0 Roadmap

## Theme

Larger capability expansion after the 0.1.x viewer and content work has stabilized.

## Candidate Areas

1. Protocol-specific diagnostic helpers or new LM tools.
2. Richer cross-capture correlation.
3. Knowledge metadata and tagging systems.
4. Larger authoring or management workflow changes.

## Entry Criteria

1. The 0.1.12 viewer and navigation work is stable.
2. The 0.1.13 content expansion has proven valuable.
3. The 0.1.14 UX changes still leave clear product gaps that require larger architecture.

## Guidance

- Do not pull 0.2.0 work forward into 0.1.x without a strong reason.
- Use 0.2.0 for changes that materially expand runtime capability or require broader schema or tool work.
