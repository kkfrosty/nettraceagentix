# NetTrace Agentix Roadmap

This folder tracks planned scope by version so each release can be picked up in a fresh thread without depending on prior chat context.

## Version Index

- [0.1.12](./0.1.12.md) — Viewer and chat navigation improvements
- [0.1.13](./0.1.13.md) — Practical agent and knowledge content expansion
- [0.1.14](./0.1.14.md) — Agent and knowledge authoring UX
- [0.2.0](./0.2.0.md) — Larger capability expansion candidates

## Working Rules

- Keep saved and live capture viewer behavior shared whenever possible.
- Treat GitHub Copilot skills as contributor or community workflow aids, not runtime analysis features.
- Keep 0.1.x releases focused and user-visible; defer broader tool or schema work until a later milestone.

## Thread Handoff

When starting a new thread for a release, reference the version file directly and state whether the goal is planning, implementation, or review.

Example: `Use docs/roadmap/0.1.12.md as the implementation scope for this thread.`
