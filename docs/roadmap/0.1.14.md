# v0.1.14 Roadmap

## Theme

Agent and knowledge authoring UX.

This release should improve discoverability and usability of the existing configuration-driven system without creating parallel management paths.

## In Scope

1. Improve knowledge discovery and category clarity in the sidebar.
2. Improve agent discoverability and explain what each agent is optimized for.
3. Consider guided create-agent and create-knowledge flows if the file-based workflow is still too hidden.

## Primary Files

- `src/views/knowledgeTreeProvider.ts`
- `src/views/agentsTreeProvider.ts`
- `src/configLoader.ts`
- `src/extension.ts`

## Notes

- Keep the JSON and markdown file model as the source of truth.
- Avoid introducing a second agent or knowledge registry.

## Verification

1. Users can understand which knowledge files and agents are relevant without opening source files first.
2. UX improvements do not change the underlying hot-reload architecture.

## Out of Scope

- Large new diagnostic tool expansion
- Knowledge tagging systems unless the simpler UX pass proves insufficient
