# v0.1.13 Roadmap

## Theme

Practical agent and knowledge content expansion.

This release should improve diagnostic quality by shipping better defaults, not by adding major new runtime architecture.

## In Scope

1. Review starter agents and improve practical specialist coverage.
2. Expand shipped knowledge content for common operational and false-positive scenarios.
3. Keep improvements content-first and avoid schema churn unless it proves necessary.

## Candidate Agent Focus Areas

- TLS and certificate troubleshooting
- DNS failure and latency analysis
- Connection establishment and reset timing
- Firewall and load-balancer edge behavior
- Suspicious traffic triage

## Candidate Knowledge Areas

- Firewall appliance quirks
- Cloud edge and NAT behaviors
- Container and service-mesh packet artifacts
- Windows and platform TCP behaviors
- Timing and latency interpretation guidance

## Primary Files

- `src/workspaceInitializer.ts`
- `src/configLoader.ts`
- `resources/defaults/.nettrace/knowledge/**`
- `resources/defaults/.nettrace/agents/**`

## Verification

1. New starter agents and knowledge files provision cleanly.
2. Hot reload still works for user edits.
3. Default provisioning does not overwrite customized workspace files.

## Out of Scope

- Broad UX redesign
- New LM tools unless content work clearly hits a hard limit
