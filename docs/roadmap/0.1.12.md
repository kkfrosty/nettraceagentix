# v0.1.12 Roadmap

## Theme

Viewer and chat navigation improvements.

This release should stay narrow, user-visible, and shared across saved and live capture flows.

## In Scope

1. Improve packet detail readability in the shared renderer.
2. Preserve PDML byte-range metadata (`pos`, `size`) in the shared packet detail model.
3. Add packet-detail to packet-bytes highlighting in the shared webview path.
4. Add chat packet links that jump the analyzed capture panel to a packet.

## Current Status

**SHIPPED — v0.1.12 released 2026-03-30**

All in-scope items implemented and verified:
- Shared packet-detail hierarchy rendering improved with CSS-driven collapse-by-default.
- PDML byte offsets and sizes preserved in the shared packet tree.
- Clicking packet-detail fields highlights bytes in both saved and live viewers.
- Chat packet references route through a command bridge and can reopen the referenced capture viewer.
- Live capture packet count fixed (no longer relies solely on stderr parsing).
- Capture filter BPF model guidance improved for AI-initiated captures.

## Notes

- Do not split saved and live viewer behavior.
- Treat PDML metadata preservation as the enabling step for byte highlighting.
- Reuse existing packet selection behavior instead of inventing a second navigation path.

## Verification

1. Detail hierarchy renders clearly in both saved and live viewers.
2. Clicking a detail field highlights the correct byte span in the hex pane.
3. Chat packet links target the active or explicitly bound capture and fail safely if the panel is not open.
4. Chat packet links can reopen a closed saved capture viewer and still select the target packet.

## Open Polish Items

1. Decide whether packet links should support more phrasing patterns than `packet` and `frame`.
2. Decide whether packet-link navigation should auto-clear display filters when the target packet is hidden.
3. Decide whether the hex pane should also visually mark the ASCII column for highlighted byte ranges.

## Out of Scope

- New heavy LM tools
- External integrations
- Large agent UX redesign
- Knowledge metadata or tagging systems
